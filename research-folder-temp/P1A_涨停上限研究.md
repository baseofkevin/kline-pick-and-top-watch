**研究日期**：2026-10-23  
**样本**：18 个周频基准日（2026-06-08~2026-10-14），4,655 只 A 股；事件级窗口 2026-06-01~2026-10-14

**性质**：研究阶段只做统计；v2.7 已按定案落地上下限（未做买可性过滤）

## 1. 口径与定义

### 1.1 事件宇宙

对每只股票、每个交易日 t：

- `close[t-1] <= MA20[t-1]` 且 `close[t] > MA20[t]`（首次收复 MA20）
- `MA20[t] >= 0.98 * MA60[t]`
- `volume[t] / mean(volume[t-5:t]) >= 1.75`
- 涨幅 `ChangePCT[t] >= 2`

这对应规则里的“放量上穿 + 结构合格”，**不要求资金流/ST/新股/新鲜度**。所以它是“候选事件”，不是最终名单。

### 1.2 最终名单

用 18 个周频 S 重放，参数与 v2.6 完全一致（`K_VOL=1.75, C2=1%, C3=0.98, MA60_GAP=0, N=4, 市值比>=0.2%`），只把横截面上限从 9.5 改成 30：

- **基线**：9.5% 上限，132 条，126 只唯一股票
- **放宽**：30% 上限，236 条，223 只唯一股票
- **新增**：104 条，103 只唯一股票

新增的 104 条不是“全部 9.5% 以上事件”，而是同时满足资金流、ST/新股、C2、新鲜度等条件的最终入选。

### 1.3 涨停状态

用事件股 OHLC + 昨收计算涨停价：

- 主板 10%、创业板/科创板 20%、北交所 30%
- 涨停价 = 昨收 × (1+幅度)，四舍五入到分
- **一字板**：最高=最低=涨停价
- **收盘封死**：收盘价 ≥ 涨停价 − 0.005（不含一字）
- **触板未封**：最高价触及涨停，但收盘低于涨停
- **未触板**：最高价未到涨停

S 日“收盘可买”= 收盘价 < 涨停价 − 0.005；S+1 同理，另看是否开盘涨停/一字。

### 2.4 与旧敏感度表的关系：不冲突

旧表：

```text
上限：5.0→49 ｜ 7.0→89 ｜ 9.0→110 ｜ 9.5→112
下限：2.0→112 ｜ 3.0→99 ｜ 5.0→63
```

这不是反例，而是**截断样本内的局部敏感度**：

- 旧池已经被 `2 <= ChangePCT <= 9.5` 截断；9.5 以上没有样本，所以“9.0→9.5 只差 2 只”只说明 **9.0~9.5 这一小段密度低**，不能说明 9.5 以上没有股票。
- 旧表的脚注也写了“无法测放宽”；要测 20.5，必须重新拉一个 `[0, 20.5]` 的池，本文做的就是这件事。
- 新池重放（同一套 v2.6 参数）：

| 上限 | 下限 2% | 下限 0% |
|---:|---:|---:|
| 9.0% | 128 | 133 |
| 9.5% | 132 | 137 |
| 15% | 222 | 227 |
| 20.5% | 236 | 241 |

- 旧表绝对数 112 是旧参数/旧口径；新基线是 132。**不要跨表比绝对数**，只看“在同一张表内，边界动一点会怎样”。
- 在新池里，9.5→20.5 增加 104 条，而 9.0→9.5 只增加 4 条：不是线性关系，因为 9.5 以上是主板涨停/20% 板的另一段分布，旧池把这部分**截掉了**。
- 下限同理：旧表 2→3 损失 12% 是“收紧”的局部斜率；新表 2→0.5 只多 5 条是“放宽”的边际。收紧和放宽本来就不对称：收紧会砍掉已在池里的边际样本，放宽只增加能过资金流/新鲜度的少数样本。两者不矛盾。

## 4. 通用数值建议

### 4.1 候选池统一上限：20.5%

| 统一上限 | 最终名单 | 新增 | 说明 |
|---:|---:|---:|---|
| 9.5% | 132 | 0 | 现状 |
| 10.5% | 202 | +70 | 只覆盖主板涨停，仍砍 20% 板 |
| 12% | 208 | +76 | 仍砍 20% 板 |
| 15% | 222 | +90 | 仍砍 20% 板涨停（20.0x） |
| 18% | 224 | +92 | 仍差 20% 板涨停 |
| 20% | 233 | +101 | 差 3 条 20% 板四舍五入（20.01/20.02/20.07） |
| **20.5%** | **236** | **+104** | **当前宇宙（无北交所）的最小完整值** |
| 25% | 236 | +104 | 与 20.5 同结果，更宽松 |
| 30% | 236 | +104 | 当前无北交所，结果同 20.5 |

**建议：`MAX_CHG = 20.5`。**

- 20.5 覆盖主板 10% 和创业板/科创板 20% 的涨停（含四舍五入到 20.0x 的 3 条）。
- 20.0 会漏掉这 3 条；15/18 会系统性砍掉 20% 板，属于新的板块偏差。
- 当前 K 线宇宙没有北交所；若以后纳入北交所，统一上限改 **30.5%**（30% 板 + 0.5 容差）。
- 不推荐 30% 作为当前值：当前没有北交所，30 与 20.5 结果相同，但更宽松、更容易纳入无涨跌幅/异常数据。

### 4.2 可买性统一容差：0.5%

- **封死判定**：`close >= limit_price - 0.005`（半分钱容差，处理四舍五入）。
- **贴近/不追判定**：`(limit_price - close) / limit_price <= 0.5%`。
- **可买**：距涨停 >0.5%，且不是封死。

为什么是 0.5%：

- 新增 104 条里，S 日要么封死（距 0%），要么距涨停 ≥0.916%；**0~0.5% 之间没有样本**。
- 0.5% 能把“封死/贴近”与“正常可买”干净分开，且不会误伤样本。
- 0.5% 是跨板块的统一容差；涨停价本身仍按 10/20/30 板块计算，不能用统一百分比代替。

### 4.3 涨幅下限：0.5%（0 也可以，但 0.5 更干净）

| 下限 | 最终名单（上限 20.5） | 新增相对 2% | 说明 |
|---:|---:|---:|---|
| 0% | 241 | +5 | 包含平盘，语义最宽 |
| **0.5%** | **241** | **+5** | 与 0 同结果，排除平盘 |
| 1% | 240 | +4 | 更保守 |
| 1.5% | 239 | +3 | 接近原口径 |
| 2% | 236 | 0 | 现状 |

**建议 `CHG_LO=0.5`。**

- 0 和 0.5 在当前样本的最终名单完全一样（241 条），但 0 允许 `ChangePCT=0` 的平盘；平盘不是“启动”，0.5 的语义更干净。
- 0.5~2% 是真正的“安静启动”区间：事件级 5 日 +0.44%~+2.37%，不差于高涨幅组。
- 如果追求最大召回，0 也可以；但不建议把下限设成负数——那会把下跌日当成启动。

### 4.4 一句话的落地参数

```text
CHG_LO = 0.5            # 涨幅下限；0 也可，但 0.5 排除平盘
CHG_HI = 20.5           # 候选池统一上限；纳入北交所改 30.5
LIMIT_DIST = 0.5        # 距涨停 <=0.5% 视为贴近/不追
SEALED_EPS = 0.005      # 收盘价 >= 涨停价-0.005 视为封死
```

板块识别只用于**算涨停价**（10/20/30），不用于候选池上限；这样既“按板块识别涨停”，又只有一个通用上限。

## 5. 对 P1-A 最小闭环的建议

只动候选池和可买性，不动 MA60/箱体：

1. `CROSS_TPL` 的 `ChangePCT >= 2` 改为 `>= 0.5`、`ChangePCT <= 9.5` 改为 `<= 20.5`；`CROSS_CACHE_VERSION += 1`，重拉横截面。
2. `judge(..., chg_lo=0.5, chg_hi=20.5)`；本地仍校验 `0.5 <= ChangePCT <= 20.5`。
3. S 日涨停状态：
   - `close >= 涨停价-0.005` → 观察池，不进入可买名单；
   - `距涨停 <=0.5%` → 标注“贴近涨停”，默认不追；
   - 其余 → 正常名单。
4. S+1 开盘/收盘涨停 → 标注“次日封死/开盘涨停”，回测按不可买处理。
5. 输出新增列：`S涨停状态`、`S距涨停%`、`S+1状态`、`d*涨幅`、`板块`。

## 6. 边界与未决

- 8/104 新增名单、49/697 事件缺 OHLC；主要来自数据源缺失/停牌/退市，未强行补齐。
- 涨停价用“昨收×幅度四舍五入到分”推算；真实交易所的涨跌停价可能因规则细节有 1 分钱差异，落地时优先用 `quote` 的 `price_ceiling`。
- 没有盘口/封单数据，无法区分“封死但可排队成交”和“完全买不到”；本文按收盘价是否等于涨停价做保守分类。
- S+1 只按收盘/开盘判断，未模拟盘中打开；2 条“开盘涨停”不等于全天买不到。
- 本文是**规则统计**，不是收益回测；新增 104 条的质量（5/10/20 日超额）尚未验证，不能把“漏了 104 条”直接当成“多赚 104 次”。
- 18 周窗口与 287 日全缓存口径不同；报告已标注，避免再把 6,688 说成 91 天。

## 8. `CHG_LO=0.5` / `CHG_HI=20.5` 定案讨论

本节把前面关于上下限的讨论、反例核对和最终取舍集中记录，避免以后只看到参数、看不到依据。

### 8.1 定案

```text
CHG_LO = 0.5
CHG_HI = 20.5
```

- 当前数据宇宙没有北交所；若以后纳入北交所，`CHG_HI` 改 **30.5**（30% 板 + 0.5 容差）。
- 下限 `0` 也可用：当前样本里 `0` 与 `0.5` 的最终名单完全一样（都是 241 条）；选 `0.5` 是为了排除平盘，语义更干净。
- 上限 `20.5` 是当前宇宙能覆盖主板 10% 与创业板/科创板 20% 涨停的**最小完整值**；`20.0` 会漏掉 3 条涨停价四舍五入到 20.01/20.02/20.07 的 20% 板。
- 这两个数只改**候选池边界**；涨停价仍按 10/20/30 板块计算，可买性另用 0.5% 的通用容差。

### 8.2 讨论过程与证据链

| 步骤 | 问题 | 结论 |
|---|---|---|
| 1 | 9.5% 上限是不是事实错误？ | 是。主板涨停约 10%，9.5% 覆盖不到；旧文档“覆盖主板涨停”写错 |

| 5 | 2% 下限有没有误伤？ | 有。18 周 146/2,580（5.7%）安静事件 <2%；事件级 5 日/20 日不差于高涨幅组 |

### 8.5 与旧敏感度表为什么不冲突

旧表：

```text
上限：5.0→49 ｜ 7.0→89 ｜ 9.0→110 ｜ 9.5→112
下限：2.0→112 ｜ 3.0→99 ｜ 5.0→63
```

- 旧表是在 `[2, 9.5]` 截断池内做的**局部敏感度**；9.5 以上没有样本，所以“9.0→9.5 只差 2 只”不能外推到 20.5。
- 新池 `[0, 20.5]` 重放后，9.5→20.5 增加 104 条；这是跨过截断边界进入另一段分布（主板涨停/20% 板），不是旧表算错。
- 旧表绝对数 112 是旧参数/旧口径；新基线 132。**不要跨表比绝对数。**
- 下限 2→3 损失 12% 是“收紧”的局部斜率；新表 2→0.5 只多 5 条是“放宽”的边际。收紧和放宽不对称，两者可以同时成立。

### 8.6 组合效应与解释边界

```text
上限 9.5 → 20.5，下限保持 2：132 → 236（+104）
下限 2 → 0.5，上限保持 20.5：236 → 241（+5）
合计：132 → 241（+109，+82.6%）；唯一股票 126 → 227
```

- 上限是主要矛盾，下限是次要修正；不要因为下限只多 5 条就否定 2% 的误伤，也不要因为下限有误伤就把上限继续放宽到 30/30.5。
- 新增 104 条中 S 日封死/一字 28 条；这说明“扩池”必须和“可买性”一起做，不能只改上限。
- 新增 104 条的前瞻收益尚未验证；本文只证明“旧上限在系统性漏样本”，不证明“新增样本一定赚钱”。
- v2.7 已把 `CHG_LO=0.5`、`CHG_HI=20.5`、`CROSS_CACHE_VERSION=2` 写入 `screen_kline.py`；S 日涨停可买性/观察池仍未落地。
